# Python Practice Codes

Comprehensive, runnable practice scripts covering essential Python foundations.

## Files Overview

1. **[01_comparison_operators.py](file:///c:/Users/srini/Desktop/Python%20Fastapi/Python%20Operters/01_comparison_operators.py)**
   - Basic comparison operators (`==`, `!=`, `>`, `<`, `>=`, `<=`)
   - Type comparison subtleties (ASCII string sorting, lists, floating-point precision)
   - Chained comparison operators (`10 < x < 30`)
   - Equality (`==`) vs Object Identity (`is`)
   - Hands-on exercises with test assertions

2. **[02_python_statements.py](file:///c:/Users/srini/Desktop/Python%20Fastapi/Python%20Operters/02_python_statements.py)**
   - Conditional branching (`if`, `elif`, `else`) and ternary expressions
   - `for` loops (`range`, `enumerate`, `zip`, dictionary unpacking)
   - `while` loops and iteration
   - Control flow (`break`, `continue`, `pass`)
   - Loop `else` blocks (`for-else`, `while-else`)
   - Pattern matching (`match-case`)
   - Hands-on challenges (FizzBuzz, Prime check, Number reversal)

3. **[03_methods_and_functions.py](file:///c:/Users/srini/Desktop/Python%20Fastapi/Python%20Operters/03_methods_and_functions.py)**
   - Standalone functions vs Object methods
   - Parameter types: Positional, keyword, default, `*args`, and `**kwargs`
   - Variable scope (LEGB rule, `global`, `nonlocal`)
   - First-class functions: `lambda`, `map()`, `filter()`, custom `sorted()` keys
   - Closures and function decorators (crucial for FastAPI route handlers)
   - Hands-on exercises (Palindrome validator, Function factory, Query string builder)

4. **[04_object_oriented_programming.py](file:///c:/Users/srini/Desktop/Python%20Fastapi/Python%20Operters/04_object_oriented_programming.py)**
   - Classes, objects, and the `__init__` constructor
   - Class attributes vs instance attributes
   - Methods: Instance methods, `@classmethod` (alternative constructors), and `@staticmethod`
   - Encapsulation with `_protected` convention and `@property` / `@setter`
   - Inheritance and `super()`
   - Polymorphism through shared interfaces
   - Dunder / magic methods (`__str__`, `__repr__`, `__add__`, `__eq__`, `__len__`)
   - Complete Bank Account & Savings Account project with automated tests

## How to Run

Run any file individually from PowerShell or terminal:

```bash
python 01_comparison_operators.py
python 02_python_statements.py
python 03_methods_and_functions.py
python 04_object_oriented_programming.py
```
