# Java Assignment 8 - Error Handling

This project demonstrates custom exceptions, a single multi-catch clause, and a `finally` block that still executes when a `NullPointerException` is thrown.

## Structure

- `src/main/java/com/example/errorhandling/CustomExceptionA.java`
- `src/main/java/com/example/errorhandling/CustomExceptionB.java`
- `src/main/java/com/example/errorhandling/CustomExceptionC.java`
- `src/main/java/com/example/errorhandling/ExceptionThrower.java`
- `src/main/java/com/example/errorhandling/Main.java`

## Run

```bash
javac -d out src/main/java/com/example/errorhandling/*.java
java -cp out com.example.errorhandling.Main
```
