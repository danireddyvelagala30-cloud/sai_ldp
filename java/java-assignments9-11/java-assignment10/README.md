# Generic Singly Linked List Demo

This project demonstrates a custom generic singly linked list (`SList`) and its iterator (`SListIterator`).

## Project structure

```text
java-assignment10/
├── README.md
└── src/
    └── main/
        └── java/
            └── com/
                └── assignment10/
                    ├── SList.java
                    └── SListDemo.java
```

## Run the demo

```bash
cd java-assignment10
javac -d out src/main/java/com/assignment10/*.java
java -cp out com.assignment10.SListDemo
```
