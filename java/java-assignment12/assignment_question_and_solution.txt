10. Count male and female students in Computer Science.

HOW TO SOLVE IT:

1. Create a Student class
   - private fields: id, name, age, gender, engDepartment, yearOfEnrollment, perTillDate
   - constructor
   - getters
   - toString method

2. Create a StudentService class
   - This class contains all stream operations.
   - Use List<Student> as input.
   - Use stream() to filter, map, group, count, average, min/max, and collect results.

3. Use important Stream API methods:
   - filter()
   - map()
   - collect(Collectors.toList())
   - collect(Collectors.groupingBy())
   - collect(Collectors.counting())
   - Collectors.averagingInt()
   - Collectors.averagingDouble()
   - min(Comparator.comparingInt(...))
   - max(Comparator.comparingDouble(...))

4. Example logic:
   - Departments: students.stream().map(Student::getEngDepartment).distinct().collect(Collectors.toList())
   - Students after 2018: filter(student -> student.getYearOfEnrollment() > 2018)
   - Male students in Computer Science: filter both gender and department
   - Group by gender: Collectors.groupingBy(Student::getGender, Collectors.counting())
   - Average age by gender: Collectors.groupingBy(Student::getGender, Collectors.averagingInt(Student::getAge))
   - Highest percentage: max(Comparator.comparingDouble(Student::getPerTillDate))
   - Youngest male in Electronic: filter by gender + department, then min by age

5. Main class
   - Create the list of students
   - Create StudentService object
   - Print results for all 10 questions

SIMPLE EXPLANATION:
This assignment is testing how well you can use Java Streams to work with a list of objects and answer different queries without using loops manually for each task. The key idea is to write clean, readable code that separates:
- Student data model
- stream query logic
- main execution

This follows clean code principles and keeps the code organized.

FINAL NOTE:
The goal of the assignment is to practice lambda expressions and stream operations, especially grouping, filtering, counting, averaging, and selecting min/max values.
